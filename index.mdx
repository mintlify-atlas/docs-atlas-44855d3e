RutaMovil is a mobile-first road safety platform built with React Native that brings together drivers (transportistas), traffic authorities (autoridades), and administrators on a single real-time system. From GPS-guided navigation and accident reporting to MFA-secured dashboards and instant push notifications, RutaMovil covers the full lifecycle of road incident management.

## Get Up and Running

<Steps>
  <Step title="Set up your environment">
    Install Node.js ≥ 20, React Native CLI, Android Studio or Xcode, and clone the repository. See the [Environment Setup guide](/guides/environment-setup).
  </Step>
  <Step title="Install dependencies">
    Run `npm install` in the project root, then install iOS CocoaPods with `bundle exec pod install` inside the `ios/` directory.
  </Step>
  <Step title="Configure Firebase">
    Add your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) to enable authentication and push notifications. See the [Firebase Setup guide](/guides/firebase-setup).
  </Step>
  <Step title="Run the app">
    Start Metro with `npm start`, then launch on your target platform with `npm run android` or `npm run ios`.
  </Step>
</Steps>

<Note>
  Make sure you have completed the [React Native environment setup](https://reactnative.dev/docs/set-up-your-environment) before running the app for the first time.
</Note>
